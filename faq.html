基础

CodeVault 是免费的吗？

应用开源，代码托管在 GitHub。同步是可选功能：用官方服务或自己部署 Cloudflare Worker（免费额度够个人用）都可以。

支持 Windows / Linux / iOS 吗？

不支持。CodeVault 是 macOS 专属的菜单栏应用（macOS 15+），深度依赖 macOS 的全局快捷键与辅助功能体系。

和 Raycast / Alfred 的片段功能有什么区别？

启动器把片段当附属功能；CodeVault 把「信息速取」做核心：类型体系、标签、容器布局、密钥加密、双击写入都是为此专门设计，且本地优先、无插件依赖。

和 1Password / Bitwarden 有什么区别？

密码管理器只管凭证。CodeVault 统一收纳四类高频信息（代码 / 提示词 / 笔记 / 密钥），密钥类做本地加密，但它是「取用工具」不是「密码管理器」——浏览器自动填充等能力请继续用专业工具。

适合什么人用？

每天复制粘贴 30+ 次的电脑工作者：独立开发者、后端 / 前端 / DevOps / 安全工程师——频繁取用 token 和连接串、反复使用 prompt 模板、快速调用 shell / SQL 命令的人。

快捷键与面板

按 ⌘1 没反应。

依次检查：① 辅助功能权限已授予（设置页可见状态）；② 快捷键没有被其他 App 占用（录制时会提示冲突）；③ 权限刚授予时需要重启一次 CodeVault。详细步骤见故障排查。

全屏应用里能呼出面板吗？

可以。面板运行在高窗口层级并支持全屏辅助空间，多显示器下出现在当前活跃屏幕。

双击条目为什么有时是复制、有时直接写入？

「双击写入」开启时，只有打开面板前有可编辑文本框焦点才会写入；否则退化为复制。可在设置中关闭该行为。

快捷键可以改吗？

可以，设置中点录制即可更换，支持冲突检测。⌘⌥K 在部分键盘布局下与系统「切换键盘布局」冲突，建议换成 ⌘⇧V 等组合。

数据与安全

我的 token 存在里面安全吗？

密钥类条目的敏感字段 AES-GCM 本地加密，登录凭据只进 Keychain。但请注意：加密保护的是静态存储，不能替代密钥轮换；建议配合系统 FileVault。

不登录、纯离线能用吗？

可以。所有本地功能（片段库、快捷面板、剪贴板历史、加密）不依赖任何账号；本地备份随时可导出。

同步的数据会经过谁？

只经过你在登录时填写的那个服务端——官方服务或你自部署的 Cloudflare Worker。代码开源可审计。

换新 Mac 怎么迁移？

两条路：① 登录同一同步服务，首次同步自动拉回全集；② 在旧机器做本地备份，新机器导入。

剪贴板历史会被上传吗？

默认不会。剪贴板 iCloud 同步是独立开关，需你显式开启（仅经你自己的 iCloud）。片段库同步不包含剪贴板历史。

同步

两台设备都改了同一条目怎么办？

按更新时间「新者胜出」，旧版本被覆盖。规则透明，无手动合并界面。详见同步章节。

删除的条目会不会在另一台设备复活？

不会。近 7 天内的删除带墓碑记录，同步时删除优先。

Token 泄露了怎么办？

自部署：运行 wrangler secret put SYNC_TOKEN 重设（旧 Token 立即失效，各设备换填新值）。官方服务：门户吊销该 Token 并重新生成。

同步上限是多少？

单应用数据集 24MiB（Workers KV 单值限制）。纯文本场景（几千条片段）远达不到。

怎么自己搭一个同步服务？

同步后端是零依赖的 Cloudflare Worker，六条命令部署完成，见自部署指南。

还是没找到答案？

描述你的系统版本、CodeVault 版本和复现步骤，到 GitHub Issues 提问。

Basics

Is CodeVault free?

The app is open source, hosted on GitHub. Sync is optional: use the official service or deploy your own Cloudflare Worker (the free tier covers personal use).

Is there a Windows / Linux / iOS version?

No. CodeVault is a macOS-only menu-bar app (macOS 15+), built deeply on macOS global hotkeys and the Accessibility framework.

How is this different from Raycast / Alfred snippets?

Launchers treat snippets as a side feature. CodeVault makes information retrieval the core: type system, tags, container layouts, key encryption, and double-click typing are all purpose-built for it — local-first, no plugin dependency.

How is this different from 1Password / Bitwarden?

Password managers handle credentials only. CodeVault unifies four kinds of high-frequency info (Code / Prompt / Text / Key) with local encryption for Keys — but it's a retrieval tool, not a password manager. Keep using a dedicated manager for browser autofill.

Who is it for?

Anyone who pastes 30+ times a day: indie developers, backend / frontend / DevOps / security engineers — people who pull tokens and connection strings constantly, reuse prompt templates, and fire shell or SQL commands.

Hotkeys & panel

⌘1 does nothing.

Check in order: ① Accessibility granted (visible in Settings); ② the hotkey isn't taken by another app (recording flags conflicts); ③ restart CodeVault right after granting. Full steps in Troubleshooting.

Does the panel work over fullscreen apps?

Yes. The panel runs at a high window level with fullscreen-auxiliary spaces; on multi-monitor setups it appears on the active screen.

Why does double-click sometimes copy and sometimes type?

With “type into field” enabled, double-clicking types only if an editable field was focused before the panel opened; otherwise it copies. You can turn the behavior off in Settings.

Can I change the hotkeys?

Yes — record a new combo in Settings with conflict detection. On some layouts ⌘⌥K collides with “change input source”; switch to something like ⌘⇧V.

Data & security

Is it safe to keep my tokens in CodeVault?

Sensitive fields in Key items are AES-GCM encrypted at rest; credentials live only in the Keychain. Note that this protects data at rest — it doesn't replace secret rotation. Use FileVault alongside.

Can I use it fully offline?

Yes. Every local feature (vault, quick panel, clipboard history, encryption) works without an account, and local backup export is built in.

Who sees my synced data?

Only the endpoint you configure at sign-in — the official service or your own Cloudflare Worker. The code is open source and auditable.

How do I migrate to a new Mac?

Two ways: ① sign in to the same sync service — the first sync pulls everything back; ② make a local backup on the old machine and import it on the new one.

Is my clipboard history uploaded?

Not by default. Clipboard iCloud sync is a separate opt-in switch (via your own iCloud). Vault sync never includes clipboard history.

Sync

Both devices edited the same item — what happens?

The newer update wins; the older version is overwritten. Transparent rules, no manual merge UI. Details in the sync chapter.

Can deleted items resurrect on another device?

No. Deletes within the last 7 days carry tombstones — deletion takes precedence during sync.

My token leaked — what now?

Self-hosted: run wrangler secret put SYNC_TOKEN to reset (the old token dies instantly; update all devices). Official service: revoke the token in the portal and generate a new one.

What's the sync limit?

24 MiB per app (Workers KV value cap). Thousands of text snippets come nowhere near it.

How do I run my own sync server?

The backend is a zero-dependency Cloudflare Worker — six commands to deploy. See the self-hosting guide.
