Workflow
Workflow

从想到用，只要三步From thought to paste in three steps

每天重复 30+ 次的取用动作，压缩到肌肉记忆级别。

The retrieval you repeat 30+ times a day, compressed into muscle memory.

1

呼出面板

在任意应用中按下 ⌘1，浮动面板即刻出现在光标所在的屏幕上——包括全屏应用。快捷键可在设置中自定义。

2

敲两三个字母

按标题、语言、标签模糊搜索，最近使用的条目自动靠前，常用内容往往还在打字时就已置顶。

3

回车，粘贴

↩ 复制并关闭面板，回到原应用直接 ⌘V；开启「双击写入」后，双击条目可直接写回原应用的光标处。

1

Summon the panel

Press ⌘1 from any app — the floating panel appears on the screen your pointer is on, fullscreen apps included. The hotkey is customizable.

2

Type two or three letters

Fuzzy-search by title, language, or tag. Recently used items float up — your target is often on top before you finish typing.

3

Return. Paste.

↩ copies and closes the panel; ⌘V back in your app. With “double-click typing” on, a double-click writes straight into the focused field.

Features

为「取用」而生，不止是收藏Built for retrieval, not just collecting

收藏类 App 的问题是存了就忘。CodeVault 的一切设计都围绕「存得快、找得到、用得上」。

Collecting apps fail because you file and forget. Everything in CodeVault is designed around store fast, find instantly, use immediately.

全局快捷面板

不切应用的浮动面板，支持全屏覆盖。键盘优先操作：↑↓ 导航、⌘+数字 直选、esc 即走。

自定义布局

把最常用的片段拖进「容器」，自由排布与缩放，打开面板即是你的专属工作台，而不是一串搜索结果。

剪贴板历史

内置剪贴板管理：自动记录复制历史，支持置顶、标签、来源应用，历史中的内容一键存入片段库。

密钥本地加密

密钥类条目敏感字段使用 AES-GCM 加密存储，登录凭据只进 Keychain。不登录任何账号也能完整使用。

多设备同步

填入「服务地址 + API Token」即开启同步：每 5 分钟自动全量合并，新者胜出，删除有墓碑不会复活。

自部署友好

同步后端是一个零依赖的 Cloudflare Worker，10 分钟部署到你自己的域名，数据不出你的掌控。

Global quick panel

A floating panel over any app, fullscreen included. Keyboard-first: ↑↓ to navigate, ⌘+number to jump, esc to dismiss.

Custom layouts

Drag your most-used snippets into containers and arrange them freely. Opening the panel reveals your personal workbench, not a list of search results.

Clipboard history

A built-in clipboard manager: automatic copy history with pinning, tags, and source-app icons. Send any history item straight to your vault.

Local key encryption

Sensitive fields in Key entries are AES-GCM encrypted at rest; credentials live only in Keychain. Fully functional with no account.

Multi-device sync

Enter a server address + API token to enable sync: full merge every 5 minutes, newest-wins conflicts, tombstoned deletes that never resurrect.

Self-hosting friendly

The sync backend is a zero-dependency Cloudflare Worker — deploy it to your own domain in 10 minutes. Your data never leaves your control.

FAQ

常见问题Frequently asked

CodeVault 和 Raycast / Alfred 的片段功能有什么区别？

启动器把片段当作附属功能，CodeVault 把「信息速取」做成了核心体验：类型体系、标签、容器布局、密钥加密、取用行为都是围绕高频取用专门设计的，且完全本地优先、无插件依赖。

我的 token 存在里面安全吗？

密钥类条目的敏感字段使用 AES-GCM 本地加密，登录凭据只存 Keychain；同步数据仅在你登录后发送到你指定的服务端（可以是自部署）。建议生产密钥定期轮换，并配合系统 FileVault 使用。

需要辅助功能权限吗？

全局快捷键与「写入输入框」需要辅助功能（Accessibility）权限。首次启动的引导页会引导你授权，也可稍后在 系统设置 → 隐私与安全性 中开启。

可以不同步、纯离线使用吗？

可以。不登录即是纯本地应用，所有功能（快捷面板、剪贴板历史、加密存储）都可离线使用，另支持本地备份导出。

支持 Windows / Linux 吗？

不支持。CodeVault 是 macOS 专属应用，深度依赖 macOS 的全局快捷键、辅助功能与菜单栏体验。

更多文档在哪里？

完整教程见 使用指南（安装、快捷面板、同步、自部署、设置参考），常见问题见 FAQ。

How is this different from Raycast or Alfred snippets?

Launchers treat snippets as a side feature. CodeVault makes information retrieval the core experience — type system, tags, container layouts, key encryption, and paste behaviors are all purpose-built for high-frequency retrieval, fully local-first with no plugin dependency.

Is it safe to keep my tokens in CodeVault?

Sensitive fields in Key entries are AES-GCM encrypted at rest, and credentials live only in the Keychain. Synced data only goes to the server you explicitly configure — which can be your own. Rotate production secrets regularly and use FileVault.

Does it need Accessibility permission?

Global hotkeys and “type into field” need the Accessibility permission. First-run onboarding walks you through granting it; you can also enable it later under System Settings → Privacy & Security.

Can I use it fully offline?

Yes. Without signing in it's a purely local app — quick panel, clipboard history, and encrypted storage all work offline, and local backup export is built in.

Is there a Windows / Linux version?

No. CodeVault is a macOS-only menu-bar app, built deeply on macOS global hotkeys, Accessibility, and the menu-bar experience.

Where are the full docs?

See the User Guide (install, quick panel, sync, self-hosting, settings reference) and the FAQ.
